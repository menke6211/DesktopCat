# 🐱 Desktop Cat v1.0

一個完整功能的桌面虛擬寵物貓咪遊戲，建構在 Electron + Vue 3 + TypeScript 上。

## ✨ 功能特性

### 🎮 核心遊戲玩法
- ✅ **動畫精靈系統** - 使用 Sprite Sheet 實現流暢的四向行走動畫
- ✅ **拖動互動** - 可自由拖動貓咪到任何位置
- ✅ **多種互動** - 餵食、玩耍、睡眠、梳毛
- ✅ **自動行為系統** - 貓咪會自主活動、行走、睡眠
- ✅ **狀態管理** - 完整的飢餓、能量、快樂、健康系統
- ✅ **心情系統** - 根據狀態自動切換心情（開心、飢餓、困睡等）

### 📊 進度系統
- 等級系統（通過互動升級）
- 經驗值積累
- 健康狀況追蹤

### 💾 數據持久化
- 自動保存狀態到本地
- 下次啟動時恢復進度

### 🎨 視覺效果
- 精美的漸變背景
- 響應式 UI 設計
- 平滑的動畫過渡
- 像素藝術貓咪精靈

## 🚀 快速開始

### 安裝依賴
```bash
npm install
```

### 開發模式
```bash
npm start
```

這會同時啟動 Vite 開發服務器和 Electron 應用。

### 構建
```bash
# 構建前端
npm run build

# 打包 Electron 應用
npm run electron-build
```

## 🎯 遊戲機制

### 狀態系統

| 狀態 | 範圍 | 說明 |
|------|------|------|
| 🍖 飢餓度 | 0-100 | 隨時間增加，餵食時減少 |
| ⚡ 能量 | 0-100 | 玩耍時減少，睡眠時恢復 |
| 😊 快樂度 | 0-100 | 通過互動增加 |
| ❤️ 健康度 | 0-100 | 梳毛增加，忽視時減少 |

### 心情判定

- **😊 開心** - 所有狀態正常
- **😋 飢餓** - 飢餓度 > 80
- **😴 困倦** - 能量 < 30
- **🤩 興奮** - 正在玩耍
- **😠 不開心** - 快樂度 < 30

### 動作系統

每個動作都有特定的效果：

| 動作 | 效果 | 冷卻時間 |
|------|------|----------|
| 🍖 餵食 | 降低飢餓度 40 | 需要飢餓 > 10 |
| 🎾 玩耍 | 增加快樂度 25 | 需要能量 > 20 |
| 😴 睡眠 | 恢復能量 60 | - |
| 🧹 梳毛 | 增加健康度 20 | 需要健康 < 95 |

## 🎨 美術資源

遊戲使用 Sprite Sheet 進行動畫渲染。需要放置 `cat-sprite.png` 在 `public` 目錄。

### Sprite Sheet 結構
- **向右行走** - 7 幀
- **向左行走** - 7 幀
- **向上行走** - 14 幀
- **向下行走** - 14 幀
- **待機動畫** - 10 幀（坐著、清理等）
- **睡眠動畫** - 4 幀

## 🔄 自動行為

貓咪會根據其狀態自動執行以下行為：

1. **隨機行走** - 每 3-8 秒隨機方向行走
2. **自動坐下** - 走累了會坐下休息
3. **疲倦時睡眠** - 能量不足會自動睡覺
4. **自我梳理** - 偶爾會自我清潔

## 💡 遊戲提示

1. 定期餵食貓咪保持其快樂
2. 當能量充足時和貓咪玩耍
3. 讓困倦的貓咪充分休息
4. 經常梳毛保持貓咪健康
5. 通過互動升級並獲得經驗值
